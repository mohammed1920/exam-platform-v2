# خريطة النقل المرحلي والاعتماديات — 2026-10-28

## القرار الحالي

لا توجد دفعة نقل لملفات التشغيل ثبت أنها منخفضة المخاطر بما يكفي للتنفيذ فورًا. ملفات الواجهة مرتبطة بمسارات ثابتة في HTML، وبناء GitHub Pages، وبمراجع JavaScript قد تكون ديناميكية. النقل قبل تتبع هذه المراجع قد يكسر النشر أو وظائف الموقع. لذلك هذه المرحلة توثّق حدود النقل المطلوبة بدل تنفيذ نقل تخميني.

## قواعد ملزمة

- التعديل مباشرة على `main` فقط؛ لا فروع ولا PRs.
- لا تغيير في أسماء أو محتوى أو معرّفات بيانات الكتب والأسئلة والقوانين.
- لا تعديل على قواعد Firebase أو المصادقة أو إعادة تصميم الكتب ثلاثية الأبعاد.
- لا نقل لملف تشغيل حتى تُحدّث جميع مستهلكاته في نفس التغيير، ثم ينجح فحص JSON/الأصول/الصياغة وبناء حزمة Pages.
- أي تغيير في مسارات Vercel يتطلب فحصًا منفصلًا لنقاط `/pulpit/:id` و`/sitemap.xml` والبحث.
- لا يُعد نجاح CI بديلًا عن الاختبار الوظيفي والبصري داخل المتصفح.

## أول تغيير آمن مقترح

أول دفعة تنفيذية يجب أن تكون تغييرًا توثيقيًا فقط، أو تعديلًا صغيرًا لا يغيّر مسارات التشغيل. لا أوصي بنقل ملفات JavaScript أو CSS أو البيانات في هذه المرحلة؛ لم يُثبت بعد عدم وجود مراجع ديناميكية خارج ما يستطيع المدقق الساكن اكتشافه.

## بوابات التحقق لكل دفعة لاحقة

1. قراءة آخر نسخة من `main` والـSHA قبل التعديل.
2. البحث عن كل مراجع المسار القديم في HTML وCSS وJS وJSON وMarkdown وYAML وملفات البناء.
3. فحص مراجع `window.*`، و`document.getElementById`، و`querySelector`، و`import()` و`fetch()`، ومراجع الملفات المكوّنة من سلاسل.
4. تنفيذ تغيير واحد محدود، وتحديث كل المستهلكين في commit نفسه.
5. تشغيل `node scripts/validate-static-project.mjs`، و`python3 validate_project.py`، و`node --check` لكل ملفات JS/MJS، ثم `bash scripts/build-pages-bundle.sh /tmp/mizan-pages-bundle-verify` و`node scripts/build-petition-index.mjs /tmp/mizan-pages-bundle-verify/data/petitions` على نسخة عمل محلية.
6. مراجعة محتويات الحزمة الناتجة، ثم التحقق من CI وحالة Vercel.
7. اختبار الوظائف المتأثرة على المعاينة. إن لم يتوفر اختبار متصفح أو اتصال مباشر، يوثّق كقيد ولا يُعلن اكتمال المرحلة.

## ما لم يُنفذ

- لم تُنقل أو تُحذف أي ملفات تشغيل.
- لم تُشغّل أوامر Node/Python محليًا في هذه الجلسة؛ لم تتوفر بيئة تشغيل المستودع عبر اتصال محلي.
- لم يُجر اختبار متصفح أو اتصال حي مع Firebase أو Vercel.
- هذه الخريطة خطة تنفيذ مبنية على قراءة الملفات الموجودة في `main` وليست إثباتًا لاكتمال الاختبارات.
