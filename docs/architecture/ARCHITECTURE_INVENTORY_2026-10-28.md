## 4. البناء والنشر

### GitHub Pages
- `scripts/build-pages-bundle.sh` ينسخ ملفات HTML/JS/CSS و`manifest.json` الموجودة في الجذر، ثم ينسخ `engine/`, `icons/`, `data/`, و`assets/`.
- السكربت يرفض مسارات إخراج غير آمنة ويتحقق من وجود ملفات نشر أساسية.
- `scripts/build-petition-index.mjs` يُشغّل بعد إنشاء الحزمة داخل `dist/data/petitions`.
- الحزمة **لا تتضمن** `api/`, `scripts/`, `reports/`, ملفات Python، أو ملفات قواعد Firebase؛ هذا مقصود للحزمة الثابتة، ويعني أن وظائف Serverless لا تعمل على GitHub Pages وحده.

### Vercel
- `vercel.json` يعيد توجيه `/sitemap.xml` إلى `/api/sitemap` و`/pulpit/:id` إلى `/api/article?id=:id`.
- `api/article.js` مسؤول عن صفحة المقال المباشرة/بيانات المقال، و`api/sitemap.js` عن خريطة الموقع الديناميكية، و`api/search-questions.js` عن بحث الأسئلة.
- يجب إبقاء `api/` و`vercel.json` في مكانهما حتى اختبار مسارات Vercel مباشرة بعد أي تغيير.

### GitHub Actions
- `update.yml` يشغّل فحص البيانات والتحقق الساكن وبناء الحزمة والنشر عند الدفع إلى `main`.
- `validate-project.yml` يعمل عند Pull Request إلى `main` أو تشغيل يدوي؛ لا يعتمد عليه وحده لتغييرات `main` المباشرة، لأن `update.yml` ينفذ فحوصات التحقق ضمن مسار النشر.
- `auto-update-books.yml` يولّد عدادات الفصول وبيانات الأسئلة وفهرس البحث ويستخدم مجموعة التزامن `content-maintenance`. سيرَا التدقيق الإملائي والجودة يكتبان تقارير إلى `main` ويستخدمان مجموعة التزامن نفسها؛ يجب مراجعة أي نقل يمس هذه الملفات أو المسارات.
- آخر تشغيل نشر راجعته: **نجاح**، Run `40596236007` على Commit `3adf0e5a6c1547443b9e87f6b25e302fce1db54c`. خطوات التحقق والبناء ورفع حزمة Pages والنشر انتهت بنجاح. هذا يثبت نجاح مسار CI المذكور فقط، لا الاختبار البصري أو الوظيفي داخل المتصفح.

## 7. Service Worker وPWA

- لا يوجد `service-worker.js` أو `sw.js` في شجرة المستودع الحالية.
- `platform-bootstrap.js` يلغي تسجيل أي Service Worker مسجّل في المتصفح؛ هذا سلوك صريح في الكود الحالي.
- `manifest.json` موجود، ويحدد صفحة التشغيل والأيقونات؛ فحص الحزمة يتحقق من وجود الأيقونات.
- لذلك لا نفترض وجود دعم Offline حالي. لا نضيف Service Worker ولا نغيّر هذا السلوك ضمن الجرد أو نقل الملفات؛ أي تغيير فيه يحتاج قرارًا واختبارات مستقلة.
