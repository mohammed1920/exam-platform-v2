## حقائق الجرد المثبتة

- لقطة المستودع عند الجرد: 347 عنصرًا في شجرة Git، منها 316 ملفًا، و66 ملفًا في الجذر، و211 ملفًا تحت `data/`.
- ملفات التشغيل موزعة بين الجذر ومجلدات `engine/`, `api/`, `data/`, `assets/`؛ لا يوجد مجلد `src/` موحد.
- `scripts/build-pages-bundle.sh` ينسخ ملفات HTML/JS/CSS و`manifest.json` من الجذر، ثم `engine/`, `icons/`, `data/`, `assets/`. لا تُنقل ملفات التشغيل قبل تحديث المراجع والبناء معًا.
- `index.html` يعتمد على ترتيب تحميل سكربتات كلاسيكية وواجهات `window.*`; لا تغيّر ترتيب التحميل ضمن نقل آلي.
- `vercel.json` يربط `/sitemap.xml` و`/pulpit/:id` بواجهات `api/`. هذه الوظائف لا تُنقل إلى حزمة GitHub Pages الثابتة.
- لا يوجد `service-worker.js` أو `sw.js` في الشجرة الحالية؛ `platform-bootstrap.js` يلغي تسجيل العاملات القديمة. لا نفترض دعم Offline حاليًا.
- تقرير سلامة البيانات المؤرخ 2026-10-25 يحتوي 18 ملاحظة: ملاحظتان كاذبتان تعتبران مجلدي `laws/` و`petitions/` مجلدات كتب يتيمة، و16 سؤالًا بخيار واحد تحتاج مراجعة بشرية؛ لا تعدّل البيانات القانونية تلقائيًا.
- آخر تشغيل نشر قبل تقرير الجرد، Run `40596236007` على Commit `3adf0e5a6c1547443b9e87f6b25e302fce1db54c`, اجتاز التحقق البنيوي وبناء الحزمة والنشر. تشغيل أحدث لتغييرات التوثيق جارٍ/يُراجع عبر Actions.

## ضوابط إلزامية

1. لا تبدأ النقل قبل تحديد جميع المراجع الثابتة والديناميكية.
2. لا تغيّر محتوى القوانين أو الأسئلة أو `id`/`uid` دون ضرورة مثبتة وموافقة واضحة.
3. لا تعدّل قواعد Firebase أو المصادقة ضمن التنظيم.
4. لا تضف طبقات CSS أو ترقيعات بديلة؛ عالج المصدر المسؤول.
5. حافظ على التحميل الانتقائي للبيانات، والبحث، وSEO، وsitemap، ومسارات Vercel، وحزمة Pages.
6. لا تحذف ملفًا لمجرد أنه يبدو غير مستخدم؛ افحص مستهلكيه أولًا.
7. سجّل نتائج الفحوص التي نُفذت فعلًا، ولا تدّعِ نجاح اختبار لم يُشغّل.
