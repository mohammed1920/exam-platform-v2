## ضوابط متابعة إلزامية

1. لا تبدأ نقل الملفات قبل اكتمال المرحلة 1 ومراجعة نتائجها.
2. لا تُنشأ فروع جديدة؛ العمل على `main` وفق تعليمات المستخدم الحالية.
3. لا تُحذف ملفات أو تُغيّر أسماءها لمجرد أنها تبدو غير مستخدمة.
4. قبل أي نقل، افحص مراجع HTML وJS وCSS وJSON وملفات البناء وGitHub Actions وVercel وService Worker والروابط المباشرة.
5. لا تغيّر المحتوى القانوني أو معرّفات الأسئلة والبيانات إلا لضرورة مثبتة وموافقة واضحة.
6. لا تُضعف Firebase Authentication أو قواعد Firestore/Storage.
7. لا تضف طبقات CSS أو أكواد التفافية لتجاوز المشكلة الأصلية.
8. حافظ على التحميل الجزئي للبيانات، وSEO، وsitemap، وPWA، والنشر الحالي.
9. بعد كل مرحلة، سجّل الملفات المتأثرة، والفحوص التي نُفذت فعلًا ونتائجها، والمشكلات المفتوحة، والخطوة التالية.
10. إذا تعذر التحقق من نتيجة ما، اذكر ذلك صراحة ولا تصفها بأنها ناجحة.
