# فهرس إجراءات الدعاوى في Firebase

## التصميم

- تفاصيل الإجراءات محفوظة في مجموعة `legalProcedures`، ولا تُقرأ إلا من الإدارة أو المستخدم الذي مُنح صلاحية الوصول.
- فهرس القائمة العامة محفوظ في المستند `publicIndexes/procedures`، ضمن الحقل `items` ويحتوي على `id` و`title` و`category` و`categoryTitle`.
- قيمة `category` إلزامية وثابتة: `civil` أو `criminal` أو `administrative` أو `personal`. لا يُستنتج التصنيف من عنوان الإجراء.
- لوحة الإدارة لا تنشر الإجراء في الفهرس العام ما لم يكن منشوراً وله تصنيف صحيح.
- قراءة الفهرس مسموحة للجميع؛ إنشاء الفهرس أو تحديثه أو حذفه محصور بالإدارة.
- لا يُحمّل التطبيق تفاصيل الإجراء إلا عند فتحه، وبعد تحقق صلاحية المستخدم.
- لا توجد حاجة إلى GitHub Actions أو حساب خدمة أو مفتاح JSON لمزامنة الفهرس.

## تحديث الفهرس

لوحة الإدارة تقرأ الإجراءات عند فتح إدارة المحتوى، ثم تُحدّث مستند الفهرس إذا تغيّرت قائمة العناوين المنشورة. لذلك يؤدي حفظ الإجراء أو نشره أو إخفاؤه أو حذفه إلى تحديث القائمة من خلال مسار الإدارة نفسه. تتم مقارنة القائمة الحالية قبل الكتابة لتجنب الكتابات غير الضرورية.

## نشر قواعد الأمان

بعد تحديث `firestore.rules` في المستودع، يجب نشر القواعد نفسها من **Firebase Console → Firestore Database → Rules**. حفظ الملف في GitHub وحده لا يغيّر القواعد الفعلية في Firebase.

## حدود المستند

الفهرس مستند واحد لتقليل عدد القراءات عند عرض القائمة. يجب إبقاء محتواه مقتصراً على المعرّفات والعناوين والتصنيف المنشورة، ومراقبة حجم المستند إذا توسع عدد الإجراءات كثيراً.
