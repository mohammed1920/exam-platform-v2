# 📘 منصة الاختبارات القانونية V2

منصة اختبارات قانونية حديثة وسهلة الاستخدام، مبنية بتقنيات الويب الحديثة (HTML5, CSS3, JavaScript) وتعتمد على هيكل بيانات JSON بسيط وقابل للتوسع.

## 🎯 الفكرة الأساسية

بدلاً من إنشاء مستودع لكل كتاب (كما في النسخة الأولى)، تجمع هذه النسخة **كل الكتب والفصول والأسئلة في مستودع واحد** باستخدام ملفات JSON منظمة، مما يجعل الإدارة أسهل والصيانة أقل تعقيداً.

## 🏗️ المعمارية

```
Frontend (HTML + CSS + JS)
    ↓
Exam Engine (JavaScript)
    ↓
Data Layer (JSON Files)
```

## 📚 نظام البيانات

### books.json
ملف يحتوي على قائمة الكتب المتاحة:

```json
[
  {
    "id": "law_penal",
    "title": "قانون العقوبات العام",
    "author": "مستشار قانوني",
    "description": "دراسة شاملة لقانون العقوبات العام",
    "chapters": 5,
    "color": "#d4af37"
  }
]
```

### ملفات الفصول (chapter_X.json)
كل فصل يحتوي على مجموعة من الأسئلة:

```json
{
  "id": "law_penal_ch1",
  "book_id": "law_penal",
  "chapter": 1,
  "title": "الفصل الأول - أساسيات القانون الجنائي",
  "questions": [
    {
      "id": 1,
      "q": "ما هو تعريف الجريمة؟",
      "options": ["الخيار أ", "الخيار ب", "الخيار ج", "الخيار د"],
      "correct": 1,
      "explanation": "شرح الإجابة الصحيحة..."
    }
  ]
}
```

## ⚙️ طريقة العمل

1. **تحميل الكتب:** عند فتح الموقع، يتم تحميل قائمة الكتب من `books.json`
2. **اختيار كتاب:** المستخدم يختار كتاباً من القائمة
3. **اختيار فصل:** يتم عرض فصول الكتاب المختار
4. **بدء الاختبار:** المستخدم يبدأ الاختبار لفصل معين
5. **الإجابة على الأسئلة:** يتم عرض الأسئلة واحداً تلو الآخر مع تغذية راجعة فورية
6. **عرض النتائج:** بعد انتهاء الاختبار، يتم عرض النتائج والدرجة
7. **مراجعة الأخطاء:** المستخدم يمكنه مراجعة الأسئلة التي أخطأ فيها

## 🚀 التشغيل المحلي

### المتطلبات
- متصفح ويب حديث
- خادم ويب محلي (اختياري لكن مفضل)

### بدء التشغيل

#### الطريقة 1: استخدام Python
```bash
cd exam-platform-v2
python -m http.server 8000
```

ثم افتح المتصفح على: `http://localhost:8000`

#### الطريقة 2: استخدام Node.js
```bash
cd exam-platform-v2
npx http-server
```

#### الطريقة 3: فتح الملف مباشرة
يمكنك فتح ملف `index.html` مباشرة في المتصفح (لكن قد لا تعمل بعض الميزات بسبب قيود CORS).

## 🎨 المميزات

- ✅ **مستودع واحد:** كل الكتب والأسئلة في مكان واحد
- ✅ **سهل التعديل:** تعديل ملفات JSON فقط دون الحاجة لتعديل الكود
- ✅ **تصميم حديث:** واجهة مستخدم جميلة وسهلة الاستخدام
- ✅ **دعم اللغة العربية:** كامل الدعم للغة العربية
- ✅ **مؤقت:** تتبع الوقت المستغرق في الاختبار
- ✅ **تغذية راجعة فورية:** عرض الإجابة الصحيحة والشرح فوراً

- ✅ **حفظ النتائج:** حفظ النتائج في localStorage
- ✅ **تصميم مستجيب:** يعمل على جميع الأجهزة (موبايل، تابلت، ديسكتوب)

## 📖 كيفية إضافة كتاب جديد

1. أضف مجلد جديد في `data/` باسم معرف الكتاب (مثل `law_commercial`)
2. أضف ملفات `chapter_1.json`, `chapter_2.json`, إلخ
3. أضف الكتاب إلى `data/books.json`

مثال:
```json
{
  "id": "law_commercial",
  "title": "القانون التجاري",
  "author": "مستشار قانوني",
  "description": "شرح شامل للقانون التجاري",
  "chapters": 3,
  "color": "#f59e0b"
}
```

## 📖 كيفية إضافة أسئلة جديدة

1. افتح ملف الفصل المطلوب (مثل `data/law_penal/chapter_1.json`)
2. أضف سؤال جديد في مصفوفة `questions`:

```json
{
  "id": 6,
  "q": "السؤال الجديد؟",
  "options": ["الخيار 1", "الخيار 2", "الخيار 3", "الخيار 4"],
  "correct": 0,
  "explanation": "شرح الإجابة الصحيحة"
}
```
